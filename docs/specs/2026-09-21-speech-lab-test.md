# 语音实验测试说明

> **日期**：2026-09-21  
> **分支**：`experiment/speech-lab`  
> **入口**：设置 → 实验 → 语音实验（`/lab/speech`）  
> **目的**：一次测完听写、麦克风、朗读、闭集匹配，决定读音小游戏走哪条路

测完后把实验页「流程」导出的 JSON 发给我就行。不必对着本文勾选。

晚上在 iPad 上：设置 → 实验 → 语音实验 → **流程** → 开始，跟着屏幕做。测完点「发给自己」或「复制 JSON」。进度存在本机，第二天还能再导出。

本文仅作对照；**以 App 内流程 + 导出文件为准**。

---

## 1. 测什么、怎么判

| 听写 A（Web Speech） | 麦克风录音 | 结论 |
|---|---|---|
| 主屏 PWA 能稳定听出选项 | — | **走路线 A**，可以做读音选路 |
| 不行 | 能录音并回放 | 听写这条路否决；以后才考虑离线模型 |
| 不行 | 也不行 | 游戏只能点选，读音不能作为主操作 |

Safari 标签页只作对照，**不能代替主屏 PWA**。电脑 Chrome（即使开了 iPad 模拟）也不能下结论。

## 2. 开始前

1. 确认跑的是分支 `experiment/speech-lab`，不是线上旧包。已安装的 GitHub Pages 主屏图标里**没有**这个实验页。
2. **主结论必须来自 iPad 主屏打开的 PWA**。地址必须是 `https://` 或本机 `localhost`。用 `http://电脑IP:3100` 打开时，麦克风和听写会假失败，不要记成结论。
3. 不要用微信内置浏览器。
4. 第一次进入若整页空白：硬刷新一次再进。这是懒加载偶发失败，不是实验本身坏了。
5. 建议同一套步骤测两遍：
   - **环境 A**：iPad 主屏图标打开（必测）
   - **环境 B**：同一 iPad 的 Safari 标签页（对照）

把当前在测的环境记在这里：

- [ ] 环境 B · iPad Safari 标签页
- 系统版本：____________
- 打开方式：主屏图标 / Safari 地址栏（圈一个）
- 地址：____________

## 3. 打开实验页

1. 打开 App，底部点「设置」
2. 点「实验 → 语音实验」
3. 页面应出现标题「语音实验」，顶部有环境 / 听写 A / 麦克风 / 朗读 / 闭集

若空白或立刻报错：硬刷新后再进一次，并把现象记在第 9 节。

## 4. 环境页（先看能力，先别说话）

默认就在「环境」页签。看顶部摘要和列表，把值抄下来。

| 项 | 主屏 PWA | Safari 标签页 |
|---|---|---|
| `navigator.standalone` | | |
| `display-mode: standalone` | | |
| `isSecureContext` | | |
| SpeechRecognition | | |
| getUserMedia | | |
| MediaRecorder | | |
| 录音 MIME | | |
| speechSynthesis | | |
| 音色数量 | | |

怎么读：

- 主屏打开时，`navigator.standalone` 或 `display-mode: standalone` **至少有一个为是**，否则你测的不是主屏 PWA。
- `isSecureContext` 必须为是，否则后面的听写/麦克风作废。
- SpeechRecognition 为「无」：听写 A 会直接失败，仍要测麦克风。
- 点一次「重新探测」，确认数字没有异常跳变。

## 5. 听写 A（一票否决项）

1. 切到「听写 A」
2. 语言先选「中文 zh-CN」
3. 点「开始听写」，看到按钮变成「停止」后再读
4. 最多等待 8 秒；没停可手动点「停止」
5. 看「结果」「采用来源」和「全部候选」

新版实验按以下优先级取结果：

1. Safari 返回 `final`：使用最终结果。
2. 没有 `final`，但「正在听」已稳定命中选项：采用稳定的 interim。
3. 识别结束仍没有 `final`：采用最后一次非空 interim 兜底。

例如「正在听」显示“苹果苹果”、最终结果为空时，实验会用“苹果苹果”继续闭集匹配，而不再记为纯失败。

每个词读 **10 次**。对 = 最终结果或候选里能看出这个词（同音字也算对，例如「苹果」变成「蘋果」）。错了把实际识别写在备注。

### 5.1 中文 zh-CN

| 词 | 对 | 错 | 备注（写识别原文） |
|---|---|---|---|
| 苹果 | /10 | /10 | |
| 香蕉 | /10 | /10 | |
| 西瓜 | /10 | /10 | |

### 5.2 英文 en-US

切到「英文 en-US」，同样各 10 次。

| 词 | 对 | 错 | 备注 |
|---|---|---|---|
| apple | /10 | /10 | |
| banana | /10 | /10 | |
| window | /10 | /10 | |

另外请勾：

- [ ] 点开始后有系统麦克风授权（记下：只弹一次 / 每次都弹 / 没弹）
- [ ] 授权拒绝后，页面有「听写失败」一类提示，没有卡死
- [ ] 日志里出现过 `onstart`（出现过就说明听写真正跑起来了）
- [ ] 日志里出现过 `error code=...`（有的话把 code 抄这里：____________）

判定（主屏 PWA 为准）：

- [ ] 可用：中文三个词合计正确率大致 ≥ 70%，且能反复开始/停止
- [ ] 勉强：能出字，但经常听错或经常 `no-speech` / `network`
- [ ] 不可用：没有 `onstart`、立刻 error，且 final / interim 都没有可用文本

## 6. 麦克风通路

不识别内容，只验证主屏能不能拿到麦克风。

1. 切到「麦克风」
2. 点「开始录音」，说一两句
3. 点「停止录音」
4. 用出现的播放条回放

勾选：

- [ ] 能开始录音（有系统授权）
- [ ] 停止后出现播放条
- [ ] 能听回自己的声音
- [ ] MIME 有值（抄下来：____________）
- [ ] 失败（把红色报错或日志抄这里：____________）

## 7. 朗读

1. 切到「朗读」
2. 中文下点「朗读『苹果』」，应出声
3. 切英文，点「朗读『apple』」，应出声
4. 点「停止朗读」，声音应立刻停
5. 先点朗读，声音还在时立刻切到「听写 A」点「开始听写」：朗读应被掐掉，不应把自己的示范音听进去

勾选：

- [ ] 中文能出声
- [ ] 英文能出声
- [ ] 「停止朗读」有效
- [ ] 开始听写会打断朗读
- [ ] 完全没声音（记：____________）

## 8. 闭集选路（模拟游戏）

### 8.1 点选兜底（不依赖听写）

1. 切到「闭集」
2. 点「用点选」
3. 分别点 苹果 / 香蕉 / 西瓜

预期：绿色结果为「走『苹果』」等，分数 100%。

- [ ] 三个中文选项点选都正确
- [ ] 切英文后，apple / banana / window 点选都正确

### 8.2 听写选路（听写 A 可用时必做）

1. 点「用听写」
2. 中文下点「读一个选项」，分别读 苹果、香蕉、西瓜，各 **5 次**
3. 英文同样各 5 次

| 语言 | 词 | 走对 | 没听清 | 走错 |
|---|---|---|---|---|
| 中文 | 苹果 | /5 | /5 | /5 |
| 中文 | 香蕉 | /5 | /5 | /5 |
| 中文 | 西瓜 | /5 | /5 | /5 |
| 英文 | apple | /5 | /5 | /5 |
| 英文 | banana | /5 | /5 | /5 |
| 英文 | window | /5 | /5 | /5 |

点选项卡片（在「用听写」模式下）会朗读示范音，不是选路。

1. 在实验页点「复制」（会带上环境信息和全部日志）
2. 把剪贴板内容连同本文勾选结果一起发回
