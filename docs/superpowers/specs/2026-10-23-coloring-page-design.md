# 涂色页设计

> 日期：2026-10-23
> 状态：待评审
> 范围：给小孩涂色的独立页面。内置 SVG 线稿，家长可从 iPad 导入图片。

## 1. 背景

Kid Manage 是给约 5 岁儿童使用的 PWA。现有闭环是任务打卡、积分、宠物和奖励。涂色不进入这条闭环。

内置线稿是 `public/宠物填色线稿 · iPad 竖屏 1024×1366 · 可换装.svg`。画板为 1024×1366。文件是真实 SVG，没有嵌位图。里面有 3437 条填充路径：黑色 827 条、白色 1507 条、灰色 1103 条。灰色有多种深浅，是点阵图描摹后留下的灰边。文件没有分组，也没有名字。文件名里的「可换装」在内容里没有对应图层。

同一张图曾经以 PNG 预览出现过。宽 461 和宽 767 的 PNG 在放大后线条会软。使用 SVG 显示线稿，是为了放大后黑线仍然清楚。

## 2. 目标

- 底部导航进入涂色。画册包含内置线稿和家长导入的图。
- 默认手涂，可切换块填充。两种模式画在同一层颜色上，切换不擦色。
- 可以捏合放大。内置图的黑线在放大后保持清楚。
- 每张线稿最多一条「接着涂」进度。半成品库保存还能改的颜色层。成品库保存不能再涂的合成图片。
- 色板有 40 个固定色，另有一个自由调色入口。

## 3. 非目标

- 不连接任务、积分、宠物或奖励。
- 不做换装。
- 不把 SVG 里的白色路径逐条当作可点色块。
- 不把手指笔迹记成矢量路径。
- 不新增 HEIC 解码库。
- 第一版不调节笔宽，不提供清空全部，不保留跨次进入的撤销记录。

## 4. 入口与页面

底部导航新增「涂色」，与首页、任务、宠物、商城、设置并列，成为第 6 项。窄手机上会挤，iPad 上空间足够。标签用「涂色」。

页面：

| 路径 | 作用 |
| --- | --- |
| `/coloring` | 画册。内置图与导入图放在一起。有接着涂的图显示角标。入口进入半成品库、成品库，并添加图片。 |
| `/coloring/paint/:templateId` | 从线稿涂色。 |
| `/coloring/drafts` | 半成品列表。 |
| `/coloring/drafts/:draftId` | 继续涂这份半成品。工具与线稿涂色相同。 |
| `/coloring/finished` | 成品列表。 |
| `/coloring/finished/:finishedId` | 只查看合成图片，可删除。没有画笔、填色、橡皮和调色。 |

一根手指涂色或填色。两根手指放大和移动。放大最小为适配屏幕，最大 4 倍。

返回画册视为中途离开，并写入当前编辑对象的自动保存。见第 7 节。

## 5. 画面叠放

从下到上三层：

1. 白纸。
2. 颜色层。一张透明位图。手涂、橡皮和块填充都改这张图。
3. 线稿层。盖在颜色上，使用正片叠底。白色透出下面的颜色，黑色留在上面。这一层不接收画笔。

内置线稿层使用原始 SVG，随视图缩放，放大后线条保持矢量清晰。导入的图使用缩小后的位图当线稿，放大后线条会变软。

颜色层和分区编号使用同一套像素尺寸。内置图为 1024×1366。导入图的长边不超过 1600，颜色层与之相同。视图放大只缩放显示，不把 SVG 重新栅格化成线稿。

块填充在打开图时计算一次编号，编号不显示。栅格化线稿后，足够深的像素（含黑色和灰色碎片）是墙，浅色连通区域是一块。点中某块后，把该块像素涂到颜色层。点到角色外部的空白会涂满整张背景，第一版接受这个结果。

编号失败时，手涂、橡皮、固定色和自由调色仍可用。填色入口关闭，并提示这张图暂时不能点块填充。

## 6. 颜色与工具

固定色 40 个，横滑选取，不因自由调色而改变。10 组，每组 4 个：

| 色系 | 由浅到深 |
| --- | --- |
| 红 | `#ffd0d0` `#ff8a8a` `#e23b3b` `#8f1d1d` |
| 橙 | `#ffe0c2` `#ffb15a` `#f07a1a` `#a84b00` |
| 黄 | `#fff3b0` `#ffe14a` `#f5c400` `#b8860b` |
| 绿 | `#c8f5c4` `#5dce6a` `#1f9d4a` `#0d5c2e` |
| 青 | `#c9f6f6` `#45d6d6` `#129eae` `#0b5f73` |
| 蓝 | `#d4e4ff` `#6aa6ff` `#2f6fed` `#1a3f99` |
| 紫 | `#ead7ff` `#b07cff` `#7a3ff0` `#4a1d96` |
| 粉 | `#ffd6ea` `#ff8ec4` `#e84393` `#a61e5d` |
| 棕 | `#f0d2b4` `#c48a5a` `#8d5524` `#4e2a12` |
| 无彩 | `#ffffff` `#d9d9d9` `#8a8a8a` `#1d1d1f` |

自由调色在单独入口中。两条粗滑条分别调色相和深浅。选定后立即成为当前颜色。最近一次调出的颜色存在 localStorage 的一个键里，下次打开仍在。固定色板不写入这个颜色，备份也不包含它。

手涂笔宽 28 像素，橡皮 36 像素，坐标与颜色层一致。第一版不能调节笔宽。撤销最多 20 步，只留在本次打开的内存中。离开页面后撤销栈丢弃，已涂颜色按第 7 节保存。

## 7. 三种保存

数据放在现有 IndexedDB（`kid-manage`）中，并纳入现有备份与恢复。

| 对象 | 内容 | 能否再涂 |
| --- | --- | --- |
| 接着涂 | 每张线稿最多一份颜色层 | 能。下次从画册打开这张线稿时载入 |
| 半成品 | 一份颜色层，指向某张线稿 | 能。从半成品库打开 |
| 成品 | 线稿与颜色合成后的图片 | 不能。打开只有大图 |

编辑线稿时，中途离开把颜色层写入该线稿的接着涂。点「存入草稿」或「保存成品」后删除接着涂，下次从画册打开这张线稿是空白线稿。

编辑半成品时，中途离开写回这一份半成品。再点「存入草稿」会复制一份新的半成品，当前这份不改。点「保存成品」新增一张成品图片，当前半成品仍留在半成品库。

从线稿点「保存成品」同样新增成品图片，并清除这张线稿的接着涂。

合成成品失败时，不删除接着涂，也不改写正在编辑的半成品。自动保存写盘失败时，颜色留在内存中，并提示未保存成功。

## 8. 导入与删除

内置 SVG 不能删除。

导入不按扩展名拒绝。浏览器能解码成位图就使用，解码失败则提示这张图打不开。iPad 相机默认是 HEIC；设置为「兼容性最佳」后新照片是 JPEG。截图常见为 PNG，裁切或涂改后再保存常常变成 JPEG。从相册选择时，系统可能已经把 HEIC 转成 JPEG。Safari 能解码的 HEIC 可以直接用。不引入额外解码库。

长边超过 1600 像素的导入图，先缩小再保存。

删除导入的线稿前要确认。确认文案说明会同时删除它的接着涂和半成品。成品是独立图片，仍然保留。半成品和成品也可以单独删除，删除前确认。

## 9. 数据与代码位置

沿用现有分层：领域模型、Dexie 仓储、Service、页面。在 `DexieDatabase.ts` 的当前版本上加一版。文档记载的版本是 v7，实现时以文件中的实际版本为准。

新增表：

| 表 | 保存 |
| --- | --- |
| `coloringTemplates` | 内置或导入。内置只记录 public 路径和 1024×1366，线稿仍从文件读取。导入保存缩小后的位图和像素尺寸 |
| `coloringResumes` | 线稿 id 对应的一份颜色层 |
| `coloringDrafts` | 半成品颜色层和线稿 id |
| `coloringFinished` | 合成图片。可记录来源线稿 id，显示时不依赖线稿仍在 |

`BackupService` 的导出、导入和重置包含以上四张表。

内置 SVG 继续放在 `public/`。页面放在 `src/presentation/pages/Coloring/`。路由常量加到 `src/shared/constants.ts`。

## 10. 验证

项目没有测试框架，不为本功能新增测试依赖。实施后运行生产构建，并在 iPad Safari 上检查：

1. 内置 SVG 放大到 4 倍时，黑线仍然清楚，颜色从白色区域透出，黑线不被颜色盖住。
2. 点角色内部的一块，只填那一块。点角色外部空白，背景被涂满。
3. 没点保存就离开，再打开同一张线稿，颜色还在。
4. 存入草稿后，从画册再打开该线稿是空白。半成品库中可以继续涂。
5. 保存成品得到只能查看的图片。从半成品保存时，半成品仍在，成品不能进入涂色工具。
6. 切换手涂和填色不清除已有颜色。
7. 40 个固定色和自由调色都能涂上。离开后再进入，上次的自由色还在，固定色板不变。
8. 导入一张 iPad 相册图片。能解码的图出现在画册；不能解码的图有提示，不产生半张记录。
9. 删除导入线稿后，它的接着涂和半成品消失，已有成品还在。内置图没有删除入口。
10. 编号失败时填色不可用，手涂仍可用。

## 11. 风险

- 底栏 6 项在窄手机上拥挤。第一版仍放在底栏，因为小孩需要自己找到入口。
- 内置 SVG 的灰色碎片会参与分块。它们被当成墙，避免颜色从灰边漏出。显示时仍保留这些灰色，线稿外观与源文件一致。
- 正片叠底下，灰色会略微压暗下面的颜色。这是源文件灰边的结果。
- 颜色层是位图。放大到 4 倍时，色块边缘和手涂笔迹会变软。只有 SVG 线稿保持清楚。
- 备份会带上颜色层和成品图片，备份文件会变大。
