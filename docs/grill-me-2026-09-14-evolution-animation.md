## 详细记录

### Q1：分镜以规范 §7 为准

四段合约：

| 进化 | 演出 | 时长 |
|------|------|------|
| 蛋 → 孵化 | 抖动裂纹 → 碎壳飞出 → 新形态弹出 + 彩色碎纸 | 2.5s |
| 孵化 → 成长 | 白光包裹 → 散去露出新形态 + 星星 | 2.0s |
| 成长 → 成熟 | 旋转 + 光柱 → 新形态 + 皇冠/花环节拍 | 2.5s |
| 成熟 → 满级 | 金色爆发 + 彩虹光弧 + 大量星星 | 3.0s |

小鸡 / 小兔同一套时间轴，只换壳碎片和粒子颜色（沿用「类型纯外观差异」）。

### Q2：纯 FM，只补孵化碎片

白光、光柱、彩虹弧、爆发用渐变和粒子即可读懂。碎壳没有贴蛋纹的碎片时，容易退化成「抖动 + 闪光」。因此只新增 6 张壳碎片（每种宠物左 / 右 / 顶）。

### Q3：不能跳过

进化是最大奖励。5 岁容易误触。遮罩拦截喂食、抚摸和底部 Tab，时长到点后自动收起。

### Q4：无音效

PWA 手势与素材管线会扩大范围。四段视觉稳定后再按同一分镜加。

### Q5：按段染色的轻遮罩

不要整屏实心黑。用径向 vignette：宠物周围更透，四周按段染色（孵化暖白、成长白光、成熟金、满级金紫）。

### Q6：无庆祝文案

不出现「破壳啦」等字。阶段信息仍由换图、尺寸和状态栏阶段名承担。

### Q7：碎片并行

Prompt 见壳碎片文档。实现先用粘土色几何碎片占位；`evo-shell-*.png` 可加载后自动替换，不改时间轴。
