## P1 问题（8 项）

### 1. 架构：BackupService 跨层依赖

- **文件**：`src/application/services/BackupService.ts`
- **问题**：Application 层直接 import Infrastructure 实现（`JsonBackupAdapter`、`KidManageDB`）
- **违反**：Clean Architecture 要求 Application 只依赖 Domain 接口
- **修复方案**：在 Domain 层定义 `IBackupAdapter` 接口，Infrastructure 实现，通过 DI 注入

### 2. 架构：Settings 页面直连 IndexedDB

- **文件**：`src/presentation/pages/Settings/index.tsx`（约 80-91 行）
- **问题**：重置数据直接调用 `window.indexedDB.databases()` + `deleteDatabase()`
- **违反**：Presentation 绕过 Service/Repository 层
- **修复方案**：在 Application 层新增 `resetAllData()` 方法，封装数据库重置逻辑

### 3. 架构：Presentation 层直接 import Domain（18 处）

- **涉及**：`Task`, `Reward`, `Pet`, `PointBalance`, `TaskType`, `PetStage`, `PointRule`, `PetGrowthRule`, `HungerRule`
- **影响页面**：`TaskCheckin`, `TaskManage`, `Shop`, `Pet`, `Home`, `Settings`
- **具体引用**：`formatPoints`, `getTaskTypeLabel`, `FEED_POINT_COST`, `getStageConfig` 等
- **修复方案**：通过 Application 层 DTO/ViewModel 或 Presentation mapper 暴露
- **备注**：此问题优先级可降低，当前规模下影响不大，但随项目增长会成为问题

### 4. Bug：PetMiniCard 经验条显示错误

- **文件**：`src/presentation/pages/Home/PetMiniCard.tsx`（约 98 行）
- **问题**：经验条的 width 使用 `mood` 值而非 `expProgress`
- **影响**：UI 上「经验条」实际显示的是心情值，语义错误
- **修复**：改为使用正确的经验进度值

### 5. 样式：Typography class 未定义

- **文件**：`src/index.css`（`@theme` 块）
- **问题**：以下 class 在代码中使用但**未在 Tailwind 中定义**，不产生任何 CSS：
  - `text-hero`
  - `text-body`
  - `text-caption`
  - `text-heading`
  - `text-label`
- **受影响页面**：`TaskCheckin`, `TaskManage`, `CreatePetForm`, `RewardEditModal`, `TaskEditModal`
- **修复方案**：在 `index.css` 的 `@theme` 或 `@layer` 中补全 typography scale 定义

### 6. 样式：Hardcoded 颜色未使用 Theme Token

- **问题**：大量颜色在多处 hardcoded，而 `@theme` 已定义对应 token 却未使用
