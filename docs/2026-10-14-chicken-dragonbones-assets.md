# 小鸡 DragonBones 素材准备

> **日期**：2026-10-14  
> **对应设计**：[宠物装扮（DragonBones）设计规范](./specs/2026-10-08-pet-outfit-dragonbones-design.md) 第 4 节  
> **本期范围**：只做小鸡。小兔、小猫、小狗继续用原来的整张立绘。

你现在要准备的是「能换装的切片」，再在 DragonBones Pro 5.6.3 里绑到两套骨架上。现有的四张小鸡立绘是底稿，整张导出会让衣服和身体焊在一起，页面无法换装。

## 1. 这次不用动的图

这些文件留在原地，不要裁、不要放进 DragonBones：

- 蛋：`public/pets/chicken/stage-1-egg.png`
- 带背景的立绘：`*-bg.png`
- 进化蛋壳：`evo-shell-*.png`
- 小兔、小猫、小狗的全部图片

页面上的星星、爱心、圆点、花瓣、闪光也不要画进骨架。角色一点头，这些装饰会跟着歪。

## 2. 做完要交出的文件

两套，各三个文件，名字必须一致：

```
public/pets/armatures/young/young_ske.json
public/pets/armatures/young/young_tex.json
public/pets/armatures/young/young_tex.png

public/pets/armatures/grown/grown_ske.json
public/pets/armatures/grown/grown_tex.json
public/pets/armatures/grown/grown_tex.png
```

`young` 只给刚孵化用。`grown` 给成长期、成熟期、满级共用。蛋不进骨架。

可以分两步交：

1. 先做刚孵化，加上成长期。页面上就能看到小鸡站着，并做待机、吃东西、抚摸。
2. 再补成熟期和满级的身体图。没补之前，进化到这两个阶段时，身体还会暂时显示成长期的样子。

## 3. 程序认的名字

骨架里只有四个槽，从后往前画：

| 顺序 | 槽位名 | 放什么 |
|------|--------|--------|
| 最后面 | `bodyBack` | 这一阶段的身体后层：翅膀、尾巴、光环、云 |
| | `outfitBody` | 默认衣服的身体部分：围巾、以后的裙子 |
| | `bodyFront` | 这一阶段的身体前层：头、脸、肚子、脚 |
| 最前面 | `outfitHead` | 默认衣服的头饰：蝴蝶结，以后的皇冠 |

槽位名两个骨架必须相同。显示对象的名字必须和下面表格一字不差，区分大小写。

刚孵化（`young`）四张：

| 显示对象名 | 从哪张立绘来 |
|------------|----------------|
| `chicken_hatched_bodyBack` | `stage-2-hatched.png` |
| `chicken_hatched_bodyFront` | `stage-2-hatched.png` |
| `default_outfitBody` | 这张是全透明占位 |
| `default_outfitHead` | `stage-2-hatched.png` 上的蝴蝶结 |

成长以后（`grown`）八张。衣服只有一套，三个阶段共用；身体按阶段各备一对：

| 显示对象名 | 从哪张立绘来 |
|------------|----------------|
| `chicken_growing_bodyBack` | `stage-3-growing.png` |
| `chicken_growing_bodyFront` | `stage-3-growing.png` |
| `chicken_mature_bodyBack` | `stage-4-mature.png` 的翅膀和尾巴 |
| `chicken_mature_bodyFront` | 用成长期已经补好的身体 |
| `chicken_max_bodyBack` | `stage-5-max.png` 的翅膀、尾巴、光环、云 |
| `chicken_max_bodyFront` | 用成长期已经补好的身体 |
| `default_outfitBody` | `stage-3-growing.png` 的围巾 |
| `default_outfitHead` | `stage-3-growing.png` 的蝴蝶结 |

动作名也是固定的，两个骨架都要有：

| 动作名 | 做什么 |
|--------|--------|
| `idle` | 循环。身体轻轻起伏 |
| `eat` | 播一次。头向前点一下，然后回到待机 |
| `pet` | 播一次。头歪一下，然后回到待机 |

不做走路、眨眼、张嘴。

## 4. 为什么默认衣服只用成长期那一套

成长期是围巾和蝴蝶结，成熟期是公主裙和皇冠，满级是另一套礼服。程序里默认衣服只有一套，三个阶段穿同一套。

这次默认衣服就用成长期的粉色围巾和粉色蝴蝶结。成熟期、满级立绘上的裙子、皇冠、项链、鞋子先留在原图里，不要放进任何切片。以后做新衣服时再单独画。

按这个做，进化之后看到的是同一只鸡：翅膀变大，满级再加上光环和云，身上仍是那条围巾和蝴蝶结。

## 5. 切片规则

四张立绘都是 512×512，角色已经在画面中间。所有切片保持 512×512，透明背景，不要裁成紧贴角色的小图，也不要移动角色的位置。

在画图软件里把同一套切片叠回去，应该和原图重合，只是少了周围的星星和爱心。

被衣服挡住的地方要补上黄色，否则以后换掉围巾会露出破洞。头和身体的接缝两边都多留一条黄色，叠在一起，点头时才不会闪出一条缝。

### 5.1 刚孵化

原图是一只坐着的圆球：黄身体、脸上的小翅膀、橙色的脚、头顶蛋壳、粉色蝴蝶结，周围有星星。

| 文件 | 留下 | 拿掉 |
|------|------|------|
| `chicken_hatched_bodyBack.png` | 眼睛以下的黄身体 | 脸、蛋壳、蝴蝶结、脚、小翅膀、星星 |
| `chicken_hatched_bodyFront.png` | 眼睛、嘴、腮红、头顶蛋壳、脸颊小翅膀、两只橙脚。和身体交界处向下多留一截黄色。蝴蝶结原来的位置用黄色补满 | 蝴蝶结、星星 |
| `default_outfitBody.png` | 什么都不画，整张透明 | |
| `default_outfitHead.png` | 只有粉色蝴蝶结，位置与原图重合 | 身体和其他装饰 |

身体后层和身体前层叠在一起，仍然是原来那只圆鸡。蝴蝶结单独在最上面。透明的那张也要做，衣服槽不能缺。

### 5.2 成长期

原图是站着的鸡：展开的翅膀、粉色爱心围巾、带爱心的蝴蝶结、橙色的脚，周围有星星和爱心。

| 文件 | 留下 | 拿掉 |
|------|------|------|
| `chicken_growing_bodyBack.png` | 两只翅膀 | 身体、围巾、蝴蝶结、星星 |
| `chicken_growing_bodyFront.png` | 头、脸、黄身体、两只脚。围巾盖住的脖子用黄色补上。和翅膀交界处留一点黄色 | 围巾、蝴蝶结、星星、爱心 |
| `default_outfitBody.png` | 只有粉色围巾，位置与原图重合 | |
| `default_outfitHead.png` | 只有蝴蝶结，位置与原图重合 | |

### 5.3 成熟期和满级

这两张的姿势和成长期不一样。不要把整张公主图搬进骨架。

头、肚子、脚的位置，以成长期那张补好色的 `chicken_growing_bodyFront.png` 为准。成熟期和满级的 `bodyFront` 直接复制这张。

`chicken_mature_bodyBack.png`：从成熟期立绘里取出一对大翅膀和尾巴，肩膀对齐成长期翅膀的起点。裙子、皇冠、项链、鞋子、花瓣、星星不放进来。

`chicken_max_bodyBack.png`：从满级立绘里取出大翅膀、尾巴、头后面的光环、脚下的云。翅膀起点仍对齐成长期。光环在头后面，云在脚底下。礼服和皇冠不放进来。

## 6. 在画图软件里怎么切

用能分层、能导出透明 PNG 的软件。Mac 上可以用免费的 [Photopea](https://www.photopea.com/)（网页里的 Photoshop）。

1. 打开对应的立绘。画布保持 512×512。
2. 复制出上表里的每一层。每一层都是一张完整的 512×512，角色位置不动。
3. 用橡皮擦或蒙版去掉该层不该有的部分。橡皮擦掉的地方是透明，不要涂成白色或黑色。
4. 需要补色的地方，用旁边的黄色点一下，吸色后轻轻补上。补色只填被衣服挡住的皮肤，不要改五官。
5. 把这一套图层全部打开，对照原图看是否重合。
6. 每层单独导出 PNG。文件名用第 3 节的显示对象名，例如 `chicken_hatched_bodyFront.png`。

`default_outfitBody.png` 在刚孵化这套里是全透明。新建 512×512 透明画布，直接导出即可。

## 7. 在 DragonBones 里怎么做

软件用 **DragonBones Pro 5.6.3**。打开后如果要求登录，那是别的版本，关掉换 5.6.3。不要用 Spine。

先做 `young`，做完再新建一个项目做 `grown`。两个项目不要画在一起。

### 7.1 新建骨架

1. 新建项目。
2. 创建龙骨动画，选骨骼动画模板，完成。
3. 在场景树里双击骨架根，改名为 `young`（另一个项目改名为 `grown`）。
4. 场景里只留这一个骨架。

### 7.2 摆骨骼

只做两根会动的骨头：

1. 根骨骼留在场景原点，当作身体，名字用 `body`。
2. 在身体下加一根子骨骼，放在头的中心，名字用 `head`。

刚孵化的头心大约在圆球上半部。成长期的头心在眼睛和蝴蝶结之间。

吃东西和抚摸只转动 `head`。`body` 在待机里轻轻上下移动。

### 7.3 放图

1. 把切好的 PNG 拖进资源面板。
2. 建四个槽，名字正好是 `bodyBack`、`outfitBody`、`bodyFront`、`outfitHead`。
3. 绘制顺序按这个从后往前。编辑器里的层级面板上面的图盖住下面的图，把 `outfitHead` 放在最上面，`bodyBack` 放在最下面。
4. `bodyBack` 和 `outfitBody` 绑到 `body`。`bodyFront` 和 `outfitHead` 绑到 `head`。这样点头时，脸、蛋壳、蝴蝶结一起动。
5. 图片放上骨骼后，轴心用图片中心。角色在 512 图里已经居中，中心会落在骨头上。
6. 刚孵化：每个槽放一张图，显示对象名字改成第 3 节的名字。
7. 成长以后：`bodyBack` 槽里按顺序放三张，`chicken_growing_bodyBack`、`chicken_mature_bodyBack`、`chicken_max_bodyBack`，第一张是成长期。`bodyFront` 同样三张。`outfitBody` 和 `outfitHead` 各放一张。

如果拖进去会把原来的图替换掉：选中槽位，在显示列表里追加，而不是替换。列表第一张用成长期。

### 7.4 做三个动作

进入动画制作，新建三个动画剪辑，名字就是 `idle`、`eat`、`pet`。

- `idle`：大约 2 秒。身体轻微上下，设为循环。
- `eat`：大约 0.6 秒。头向前点一下再回来。播一次。
- `pet`：大约 0.6 秒。头向一侧歪一下再回来。播一次。

动作幅度小一点。头和身体交界已经多留了黄色，大角度甩头会把接缝甩开。

### 7.5 导出

1. 导出数据，格式选 JSON。
2. 不要勾选填充色。勾了之后透明区域会被涂上颜色。
3. 不要打成 zip。
4. 导出文件保持编辑器给出的名字：`young_ske.json`、`young_tex.json`、`young_tex.png`，成长项目是 `grown_` 开头。
5. 三个文件一起复制。不要单独改其中一个的文件名。`tex.json` 里面写着 png 的名字，只改外面的文件名会找不到图。

导出后放到第 2 节的两个目录里。

## 8. 交之前自己对一下

- 刚孵化四张、成长期四张都是 512×512，叠回去和原图重合，周围没有星星。
- 围巾和蝴蝶结各自单独一张，身体上已经补过黄色。
- 两个项目的槽位都是 `bodyBack`、`outfitBody`、`bodyFront`、`outfitHead`。
- 显示对象名字和动作名字与第 3 节一致。
- 每个项目只导出三个文件，没有 zip。
- 在编辑器里播放：待机一直循环，吃东西和抚摸各播一次后可以停。脸和蝴蝶结一起动。

大小不合适不用在编辑器里反复缩放。角色保持现在立绘里的大小，放进页面后如果太大或太小，告诉我，我改播放器里的缩放。

文件放好后跟我说一声。我再把小鸡接到页面上，并确认蛋还是原来的蛋图，其他三种宠物仍是原来的立绘。
